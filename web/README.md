# 管理者Web
  サーバーから取得したハンド・bet学などの記録をブラウザ上で一覧表示するための管理画面

## 必要なもの

- VS Code
- VS Code内 拡張機能 Live Serverをインストール

## 技術スタック
- HTML
- JavaScript

---

## セットアップ・起動手順

### 1. VS CodeでGo LiveをStart
VS Code画面右下の「Go Live」をクリック

ブラウザが起動し、期待する画面が出ればok

---

## ファイル構成

```
web/
├── main.py           # サーバー本体
├── requirements.txt  # 必要なライブラリ
├── poker.db          # SQLiteデータベース（起動時に自動生成）
└── README.md
```

---

## 止め方

Vs Code画面右下の「Go Live」を再クリック
